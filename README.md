# macrosiki

VBA-макросы для электронных форм ЕМД (КЖК, АКК СХ, ДАМУ, Лизинг, ЭКА).

## Правила работы

- Источник правды — файлы `.bas` / `.cls` в папках систем. Код правим в них.
- `.xlsm` — только сборка для проверки: импортировать модули (VBA-редактор → File → Import File),
  проверить работу. `ЭтаКнига.cls` — вставлять копипастой в модуль ЭтаКнига.
- Git хранит модули в UTF-8, а на диске сам перекодирует их в Windows-1251 + CRLF
  (так нужно VBA-редактору). Настроено в `.gitattributes`, VS Code — в `.vscode/settings.json`.

## Разовая настройка после перехода на CP1251

Если репозиторий был склонирован до появления `.gitattributes`, после `git pull` один раз
(предварительно закоммитив свои правки!):

```
git rm -r --cached -q .
git reset --hard
```
